# React Sign Up Page

A beautiful and modern sign up page built with React.

## Features

- Clean and modern UI design
- Form validation
- Responsive design
- Smooth animations
- Password confirmation
- Error handling

## Installation

1. Install dependencies:
```bash
npm install
```

## Running the Project

Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Build for Production

```bash
npm run build
```

## Project Structure

```
src/
  ├── components/
  │   ├── SignUp.jsx      # Sign up component
  │   └── SignUp.css      # Sign up styles
  ├── App.jsx             # Main app component
  ├── App.css             # App styles
  ├── main.jsx            # Entry point
  └── index.css           # Global styles
```

## Technologies Used

- React 18
- Vite
- CSS3
